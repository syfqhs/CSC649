# CSC649: My First Python Experiment

## Project Description

This project is a simple Python sentence counter program. It allows the user to enter a sentence and displays information about the sentence.

## Features

* Accepts a sentence from the user
* Checks whether the input is empty
* Counts the number of words
* Counts the number of characters
* Displays the entered sentence
* Classifies the sentence as short or long
* Displays a closing message

## How to Run

1. Open the project in PyCharm.
2. Open `main.py`.
3. Run the program.
4. Enter a sentence when prompted.
5. View the sentence analysis in the output.

## Example Output

```text
Enter a sentence: I love learning Python

--- Sentence Analysis ---
Sentence: I love learning Python
Word count: 4
Character count: 22
Sentence type: Long

Thank you for using the sentence counter!
```
